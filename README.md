# Colombia open data MCP server

MCP server to search and query datasets on the national open data portal.

## Overview

Lets assistants find and query public datasets directly, with the portal's licence shown for every result.

## Tools

- `search_datasets`
- `dataset_schema`
- `query_dataset`

## Interfaces

Protocol: `mcp`. Languages: es.
